# 银星智创平台 · 合并演示站

银星能源「银星智创平台」+「生产技术部部门工作台」**合并演示站**（纯前端静态站点，无后端）。

- 站点根目录 = 银星智创平台（门户首页 / 工具中心 / 智能团）
- `/workbench/` = 生产技术部部门工作台（平台内点击「部门工作台」卡片直达，右上角可返回平台）

## 说明

- 内置**脱敏演示数据**（虚构人员与任务），仅供演示用途
- AI 功能依赖公司内网「坤安 AI 中台」，公网环境会自动提示「AI 服务未接入」，其余功能全部正常
- 演示数据存于访问者浏览器本地，互不影响；可在工作台「设置 → 数据管理」中重置
